## Pipeline structure

`Programs/` contains **executable code only**. Every chain script carries a
digit-only prefix `T SS K` — tier, stage, step (0 single, 1 wrapper, 2 payload).
Driven by `Programs/0000_master.do`, all flags default 0.

```
TIER A  1010-1070  raw RAIS -> firm panel + connectivity   (Stata + 5 MATLAB)
TIER B  2010-2050  firm panel -> analysis panel            (was fenced; now open)
TIER D  4011-4132  analysis panel -> estimates             (13 estimators)
TIER E  5010-5220  estimates -> tables and figures
TIER F  6010       exhibits -> UnionSpill-paper/Replication/Figures
```

Tier C (3010/3020) is **retired** — see below. Tier D shells a fresh `stata-mp`
per estimator because `reghdfe` carries session state.

Tier B runs in **dependency order, not numeric order**:
`2010 -> 2020 (stop_after_pct) -> 2040 -> 2050 -> 2030`. 2020's tail needs
`pct_unionexp`, which 2040 derives from 2020's own output.

## Traps discovered (do not rediscover)

- **`destring industry1, replace force` in 1050 is REQUIRED.** reghdfe needs a
  numeric absorb variable; 1040:172 builds `industry1 = "1" + industry` so the
  int conversion cannot eat leading zeros. Three firms carry `"1CLA"` and go
  missing under force — intended. Removing force gives str4, which reghdfe
  cannot absorb and which does not match the published panel.
- **Zero rule.** Firms absent from `connectivity_treat_2007_2011_agg.dta` have
  ZERO connectivity, not missing. Applied at 1050's merge and enforced in 2030.
  Missing fails the exact `totaltreat_pw_n==0` test in Sample A and silently
  drops firm-years (moved direct 0.0262 -> 0.0263).
- **`merge ... update` + `keep(master match)`** resolves "match" to code 3 only,
  silently dropping codes 4 and 5 BEFORE printing its report. Dropped 2,220 of
  140,773 rows in the overlay build — the entire content of the overlay.
- **`mmerge` (community command) aborts** with a glibc "corrupted size vs.
  prev_size" heap corruption on this data. Replaced with native `merge 1:1` in
  2020/2030. Both sides carry `_merge`, so merge under a temp flag and rename.
- **Float tolerance.** Panel columns are `float` (~7 sig digits). A `1e-9`
  absolute comparison reports pure storage noise as difference — it flagged
  `lr_remdezr_h_w` on 98.5% of rows when correlation was 1.0000. Use a relative
  tolerance around 1e-6.
- **`set seed` does not make `runiform()` reproducible on its own.** Draws are
  assigned in the dataset's current physical row order. `1010:354` seeds then draws
  with no preceding sort on a unique key, so a differently ordered input resolves
  ties to different spells. Diagnostic signature: counts and tied variables move on
  0 rows while the non-tied attributes move on a handful.
- **Storage type is a silent divergence.** `2050:59` builds `lr_remdezr_h_w` with
  `gen double`; the legacy path carried it as `float`. Averaging float-rounded logs
  is not averaging double logs. `describe` both panels before blaming the estimator.
- **A whole-file `diff` can be a column swap.** `4031`'s three `*_pretrend_top_*`
  read as 102 differing lines and are bit-identical once `industry1` and
  `mode_base_month` are transposed back. Compare headers before counting lines.
- **`rc=0` from `stata-mp -b` does not mean success.** Nine estimators once
  returned 0 while producing nothing (missing log subdirectory, r603). Always
  check the output files and grep the log for `r(NNN);`.
- **`pgrep -f "pattern"` matches your own shell** if the pattern appears in the
  command line. Use `"b1[e].do"` style. A `pkill` once killed its own invocation.
