\textit{Notes:} This table reports Cattaneo, Crump, Farrell, and Feng (2024) sup-$t$ tests of the null hypothesis that the spillover treatment effect is a degree-1 polynomial (linear) in connectivity, on the balanced panel of untreated firms. For the calendar outcomes (wage and employment) the test runs on the firm-level first difference $\Delta Y_j = \overline{Y}_j^{\,post} - \overline{Y}_j^{\,pre}$ (post $=$ 2012--2016, pre $=$ 2009--2011), which removes the firm fixed effect of the panel DiD exactly, so each establishment contributes one observation. Clause counts are negotiated on the irregular CBA calendar rather than annually, so the clause test runs directly on the published firm $\times$ CBA-period panel DiD (six period fixed effects): the clause count and the connectivity $\times$ post term are residualized on the firm, and on the industry, month-of-year, microregion, and pre-treatment quartile fixed effects interacted with CBA period (all additive, so the projection is within-exact and the test is size-valid under the linear null), and the residuals are binned. The clause test uses $19{,}693$ firm-period observations across $4{,}142$ establishments and reproduces the published spillover slope to machine precision. In every case the OLS slope reproduces the panel spillover coefficient. Standard errors are clustered by establishment for the clause panel and heteroskedasticity-robust for the first-difference outcomes; inference uses 2{,}000 simulation draws on a grid of 50 points per bin. $p$-values below $0.10$ are bolded.
