\textit{Notes:} This table tests whether connectivity of other layers within the same firm spills over to a focal layer's outcomes. Each observation is a firm--layer--year cell. The balanced panel includes all layers for every spillover-sample firm; firms absent from a given layer receive zero employment ($\ln(1+0)=0$) and missing wages. Own connectivity is the layer's direct per-worker connectivity to treated firms, scaled to the P90 of the spillover sample. Cross connectivity is the employment-share-weighted sum of other layers' connectivity: $\text{cross\_conn}_{i,B}=\sum_{A\neq B}\text{conn}_{i,A}\times(\bar{n}_{i,A}/\bar{n}_{i,B})$, scaled to its own P90; observations with $\bar{n}_{i,B}=0$ are dropped. Both specifications include firm$\times$layer FE (the cross-section unit FE for the firm$\times$layer panel, absorbing time-invariant heterogeneity of each firm--layer pair). The first specification additionally includes firm$\times$year FE, so identification comes from within-firm cross-layer variation in connectivity. The second specification replaces firm$\times$year FE with aggregate year FE, so identification uses cross-firm cross-layer variation over time. Pre-trend placebo uses years 2009--2010 relative to 2011. Standard errors clustered at the firm level. $^{***}p<0.01$, $^{**}p<0.05$, $^{*}p<0.10$.
