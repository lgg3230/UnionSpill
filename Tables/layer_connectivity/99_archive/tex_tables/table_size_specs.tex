\textit{Notes:} This table reports layer-level spillover effects split by firm size, comparing small firms (below-median average December employment 2009--2011) to large firms (at or above median, corresponding to 31.7 workers). All regressions are restricted to untreated, balanced-panel firms. Connectivity is scaled to the 90th percentile of the full control sample at 2009 (same scale for both size groups) so coefficients are comparable across columns. The pre-trend (placebo) coefficient tests whether connectivity predicts differential outcomes in 2009--2010 relative to 2011, using only pre-reform years (2009--2011). Pre-trend F-test $p$-value tests joint significance of all pre-trend event-study coefficients. Within-firm specifications absorb firm$\times$year FE; identification exploits cross-layer variation within the same firm--year. Cross-firm specifications include microregion$\times$year, industry$\times$year, and mode$\times$year FE. Firm-level columns (5--6) run the standard firm-level spillover regression restricted to firms present in the layer sample and the given size group; bins are computed on the full sample before the size restriction for comparability. Standard errors clustered at the firm level. $^{***}p<0.01$, $^{**}p<0.05$, $^{*}p<0.10$.
