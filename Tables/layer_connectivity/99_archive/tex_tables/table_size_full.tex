\textit{Notes:} This table reports layer-level spillover effects split by firm size, comparing small firms (below-median average December employment 2009--2011) to large firms (at or above median, corresponding to 31.7 workers). The employment outcome is $\ln(1 + \text{layer employment})$, which is defined at zero and includes firm--layer--year cells with no workers in that layer; wage outcomes are unchanged and condition on positive layer employment. All regressions are restricted to untreated, balanced-panel firms. Connectivity is scaled to the 90th percentile of the full control sample at 2009 (same scale for both size groups) so coefficients are comparable across columns. Connectivity is set to zero for firm--layer pairs with no pre-treatment flows through that layer. The pre-trend (placebo) coefficient tests whether connectivity predicts differential outcomes in 2009--2010 relative to 2011, using only pre-reform years (2009--2011). Pre-trend F-test $p$-value tests joint significance of all pre-trend event-study coefficients. Within-firm specifications absorb firm$\times$year FE; identification exploits cross-layer variation within the same firm--year. Cross-firm specifications include microregion$\times$year, industry$\times$year, and mode$\times$year FE. Firm-level columns (5--6) run the standard firm-level spillover regression restricted to firms with pre-treatment flows through the layer and the given size group. Standard errors clustered at the firm level. $^{***}p<0.01$, $^{**}p<0.05$, $^{*}p<0.10$.
