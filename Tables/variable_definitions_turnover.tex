\footnotesize
\textbf{Notes.}

\textit{Additivity property.}
By construction, $\texttt{separations\_u} = \texttt{layoffs\_u} + \texttt{quits\_u} + \texttt{other\_sep\_u}$,
and equivalently $\texttt{turnover\_u} = \texttt{layoff\_rate\_u} + \texttt{quit\_rate\_u} + \texttt{other\_sep\_rate\_u}$.

\textit{Selection algorithm for separated spells.}
When a worker has multiple separated spells at the same establishment in a given year, one spell is selected using the same ranking criteria as the December employment selection (Lagos, 2021):
(1)~highest contracted hours (\texttt{horascontr});
(2)~among ties, highest hourly December wage (\texttt{remdezr} / (\texttt{horascontr} $\times$ 4.348), with missing/zero wages treated as~0);
(3)~random tiebreaker (seed 54321 in Stata, hash-based in Python).
The selected spell's \texttt{causadesli} code determines the separation category.

\textit{December employment.}
\texttt{firm\_emp} counts unique workers with \texttt{empdec\_lagos}$=1$ (i.e., \texttt{empem3112}$=1$ and \texttt{tempempr}$>1$), selecting one spell per worker--establishment pair via the final-rank algorithm (seed 12345).

\textit{Separation codes (\texttt{causadesli}).}
Layoffs: 10 (dismissal without cause), 11 (dismissal with cause).
Quits: 20 (resignation without cause), 21 (resignation with cause).
Other: all remaining non-zero codes (e.g., 12 = end of fixed-term, 30--32 = transfer, 40 = retirement, 50 = death, 60--74 = work accidents/disability).

\textit{Sample.}
The standalone Python script (\texttt{011b\_corrected\_turnover.py}) restricts to establishments with \texttt{lagos\_sample\_avg}$=1$ and \texttt{in\_balanced\_panel}$=1$. The Stata pipeline (\texttt{011\_rais\_to\_firm.do}) computes these measures for all establishments.
